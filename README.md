# 2026 Library Management System

Refactored OOP PHP Library System following PSR-12 standards.

## Features
- Add new books
- View all books
- Borrow books
- Library statistics and overdue reports

## Author
William Joseph R. Imperial

## Setup
1. Create database `library_db` and import tables
2. Run XAMPP (Apache + MySQL)
3. Open: `http://localhost/2026-library-system-activity/Public/index.php`

## PSR-12 Compliance
All files follow PSR-12 coding standards with strict typing.
